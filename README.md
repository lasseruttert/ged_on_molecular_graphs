# Graph Edit Distance on Molecular Graphs
Projektgruppe zur Implementierung und Evaluation verschiedener Algorithmen für Graph Edit Distance (GED) auf molekularen Graphen.
## Was ist das?
Graph Edit Distance misst die Ähnlichkeit zwischen zwei Graphen durch die minimale Anzahl von Operationen (Knoten/Kanten hinzufügen, löschen, ändern), die nötig sind, um einen Graphen in den anderen zu transformieren. Bei molekularen Graphen entspricht das der strukturellen Ähnlichkeit zwischen chemischen Verbindungen.
## Was haben wir gemacht?

- Verschiedene GED-Algorithmen implementiert und getestet
- Performance-Vergleiche auf molekularen Datensätzen durchgeführt
- Analyse von Laufzeit vs. Genauigkeit der verschiedenen Ansätze
- Verwendung der GED für Klassifikationsverfahren u. Ä.
